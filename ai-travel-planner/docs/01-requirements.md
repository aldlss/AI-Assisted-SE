# 01. 需求说明书

## 背景与目标
Web 版 AI 旅行规划师旨在通过语音/文字输入，自动生成个性化旅行路线，并在行程中提供实时辅助和费用管理能力。通过大模型理解用户意图，结合地图服务生成可执行的行程计划，支持多份计划的云端保存与跨设备同步。

## 用户画像
- 学生/上班族：预算敏感，行程紧凑，偏好性价比。
- 带娃家庭：亲子友好，节奏舒适，住宿与餐饮安全卫生。
- 轻旅玩家：美食、摄影、打卡，灵活调整路线。

## 用户故事与验收标准（摘选）
1. 作为用户，我可以用语音描述需求（目的地/天数/预算/人数/偏好），系统返回可视化行程表。
   - 验收：点击录音→结束→生成包含每日交通/住宿/景点/餐饮的计划卡片；可下载/保存。
2. 作为用户，我可以在地图上查看各景点位置与路线导航方案。
   - 验收：行程项在地图上展示 Marker，点击卡片高亮地图，支持驾车/步行/公共交通路线预览。
3. 作为用户，我可以记录/查看费用，系统给出预算执行情况与剩余提示。
   - 验收：添加支出后，预算进度条更新；支持语音快速记账（“午餐 120 元”）。
4. 作为用户，我可以注册/登录并同步我的行程与设置。
   - 验收：登录后能看到“我的行程”，包含查询、编辑、复制、导出。
5. 作为用户，我可以在设置页输入阿里云百炼和高德的 Key 以启用语音与地图。
   - 验收：设置成功后立即可用；密钥不明文存库，采用加密存储或临时会话缓存策略。

## 功能清单（MoSCoW）
- Must
  - 语音/文字采集需求，生成个性化行程（交通/住宿/景点/餐饮）
  - 预算估算与记账，查看执行进度
  - 地图展示与路线预览（高德）
  - 注册/登录，云端保存多份行程（Supabase）
  - 设置页安全注入 API Key（不写死在仓库）
- Should
  - 导出 PDF/分享链接
  - 多语言（简体中文优先，英文可选）
  - 行程的细粒度编辑（替换餐厅/酒店/景点）
- Could
  - 旅行途中实时建议与天气提醒
  - TTS 语音播报行程摘要
- Won’t (首版不做)
  - 离线地图
  - 复杂社交协作（多人实时编辑）

## 非功能性需求
- 易用性：移动端优先、地图交互流畅、加载反馈明确。
- 性能：首屏 ≤ 2.5s（本地开发参考），地图交互 < 200ms 反馈。
- 安全：从不在仓库提交密钥；使用 RLS 保护用户数据；https-only。
- 可观察性：前端错误采集、API 日志、关键路径打点（生成/记账/地图）。
- 可维护性：模块化、类型完备、Lint/Format/CI 构建；约定清晰。

## 外部依赖
- 阿里云百炼（DashScope）：ASR + LLM（Qwen）
- 高德地图：Web JS API v2（Loader + Service）
- Supabase：Auth、Postgres、RLS、Storage（可选图片）

## 合规与密钥管理
- 不在代码仓库包含任何 Key；通过设置页或运行环境变量注入。
- 用户自己的第三方 Key（若输入）采用加密存储（见架构文档的密钥策略）。
- RLS 保证同一用户仅能访问自己的行程与支出记录。
